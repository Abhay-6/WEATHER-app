# 🌤️ Weather Forecast Web Application

A responsive weather forecast web application that provides real-time weather information and a 5-day weather forecast for any city using the OpenWeather API. The application also supports location-based weather detection and a light/dark mode for an enhanced user experience.

## 🚀 Live Demo

🌐 **Live Website:** https://abhay-6.github.io/WEATHER-app/

## ✨ Features

- 🔍 Search weather by city name
- 📍 Get weather using the user's current location
- 🌡️ Display real-time temperature
- ☁️ Show current weather conditions
- 💧 Display humidity
- 💨 Display wind speed
- 📅 Display a 5-day weather forecast
- 🌙 Toggle between Light and Dark mode
- 📱 Responsive design for desktop and mobile devices
- ⚠️ Handle invalid city names gracefully

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- OpenWeather API
- REST API
